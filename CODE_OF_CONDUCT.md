# Código de Conduta

Este projeto lida com vocabulário sensível exclusivamente com o objetivo técnico de **moderação de conteúdo e proteção de pipelines de IA**.

## Padrões Esperados

- Mantenha todas as discussões em Issues, Pull Requests e revisões **estritamente técnicas, objetivas e respeitosas**.
- Use termos sensíveis apenas quando estritamente necessário para documentar uma entrada da lista ou um caso de falso positivo.
- Respeite contribuidores de diferentes idiomas, culturas e níveis de experiência.

## Comportamentos Inaceitáveis

- Assédio, ataques pessoais ou direcionamento de insultos a qualquer pessoa ou grupo.
- Uso de Issues ou PRs para disseminar discurso de ódio, spam ou conteúdo ilegal.
- Publicação de dados privados de terceiros (doxxing), incluindo nomes de usuários ou textos reais identificáveis.

Mantenedores reservam-se o direito de remover comentários, fechar Issues/PRs ou banir participantes que violem este código.
